Currently leading development of this tool alongside one other engineer, after moving
on from the chat interface project. It uses an LLM to help classify and transform data
columns against a target schema.

I designed and built the full architecture from scratch: a serverless backend on AWS
Lambda with PostgreSQL for storage (via Kysely), infrastructure defined in Terraform,
and asynchronous processing through SQS queues backed by dead-letter queues for
handling failures. On top of that, I built an LLM evaluation harness with an automated
scoring system and an LLM-as-judge approach for grading the quality of generated prose
output during data processing.
