Worked as a fullstack engineer on a frontend team building a chat interface powered by
an LLM, connecting natural-language queries to backend data services.

Contributed across the stack: the Vue-based chat UI, the Node.js integration layer that
routed conversational queries to backend endpoints, chart generation with export to
multiple formats, and multi-turn exchanges that recalculated values against live data
fetched from backend resources. This was my first hands-on experience integrating LLMs
into a product, and where I picked up the fundamentals of prompt design and grounding
model responses in real data.
